# Chicken weights analysis
Data analysis report exploring chick weights and feed types using R and RMarkdown.

## Project Overview
This repository contains a data analysis report exploring the relationship between chicken weights and different feed supplements using the built-in `chickwts` dataset in R.

## Repository Contents
- **`Chicken weights analysis.Rmd`**: The R Markdown source code containing data exploration, descriptive statistics, and graphical visualizations (boxplots).
- **`Chicken weight analysis report.html`**: The compiled HTML report.
- **`Chicken weight analysis report.pdf`**: The compiled PDF report.

## Tools Used
- **R / RStudio**
- **R Markdown** for dynamic report generation
